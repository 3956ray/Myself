# 奥德赛计划：从多个可能自我到现实原型

Myself 使用 Stanford Life Design Lab 的 Odyssey Planning 作为“可能自我”工作流。它不是预测未来，也不是要求用户一次选定终身路线；它帮助用户把模糊愿望展开为三条足够不同的 3–5 年生活，再用现实原型减少关键未知。

参考：[Stanford Designing Your Life](https://lifedesignlab.stanford.edu/dyl)、[Odyssey Planning Resources](https://lifedesignlab.stanford.edu/resources-1)。Myself 的证据、授权、实验和写回协议属于本项目自己的实现。

## 何时使用

- 首次设置已经完成当前现实与人生罗盘的候选整理；
- 面临职业、居住、关系或创造方向的长期分叉；
- 当前只有一个“正确答案”，因此迟迟不能行动；
- 旧路径失效，需要重新生成可能性。

缺少基本财务、健康、责任或时间事实时，先补当前状态。奥德赛不能绕过现实约束。

## Agent 引导顺序

Agent 每次最多问三个问题，并把用户原话、AI 推断和仍未知的内容分开。

### 1. 准备共同输入

读取当前状态、人生罗盘、投入与消耗经历、反目标、底线和已有承诺。提取：

- 必须尊重的现实约束；
- 希望增加或减少的普通生活体验；
- 已有能力、关系和资源；
- 目前只有想象、需要验证的判断。

### 2. 生成三条真正不同的生活

1. **延续线**：沿着目前方向继续，但主动设计得更好。
2. **替代线**：如果延续线从明天起不可行，会怎样生活？
3. **开放线**：基本生活得到保障、暂时放下身份和评价约束时，真正想探索什么？

三条路线必须在工作、生活结构或身份上有实质差异。换一家公司、但生活和工作方式完全相同，通常仍是同一条路线的变体。

### 3. 画出 3–5 年时间线

每条路线填写：

- 一个不超过六个词的标题；
- 每年至少一个个人里程碑和一个工作／创造里程碑；
- 普通一周怎样度过，而不只写高光事件；
- 这条路线需要的资源、能力、关系和前置条件；
- 它带来的代价、放弃项和可能触碰的底线；
- 2–3 个最值得通过现实验证的问题。

### 4. 使用仪表盘比较

本人分别评估资源充分度、吸引力、信心和一致性。评分只暴露差异，不用于计算唯一正确答案。Agent 应检查：

- 哪条路线主要来自“应该”，哪条包含本人的真实投入信号；
- 哪些路线共享同一底盘；
- 哪个结论依赖未经验证的收入、能力、关系或市场假设；
- 哪些小实验可以同时为多条路线提供信息。

### 5. 选择原型，不急着选终身答案

为每条仍有吸引力的路线提出一个低成本原型，例如信息访谈、跟随体验、小项目、公开作品、短期课程或真实申请。原型需要明确：

- 要减少的未知；
- 最早的外部反馈动作；
- 时间、金钱和精力上限；
- 成功、反对、证据不足和停止条件；
- 复查日期。

用户可以选择一条当前工作路径，但要记录选择依据和信心。选择表示“先投入并验证”，不表示其他人生已经被证明错误。

## 智囊团放在什么位置

首次访谈可以记录用户想参考的人、作品或方法，但先不让这些视角替用户生成人生方向。三条奥德赛草案形成后，再按需调用智囊团：

1. 检查每条路线的盲点、代价和隐藏假设；
2. 提供用户尚未考虑的原型，而不是替用户投票；
3. 区分作者原始观点、用户受其影响的陈述和 Agent 的应用推断；
4. 最终取舍仍由用户根据人生罗盘和现实证据作出。

## 写回位置

- 三条路线与当前工作假设：`02 战略/三年情景.md`；
- 具体原型：`06 实验/`；
- 重要取舍：`05 日志/决策日志.md`；
- 实际行动和结果：实验执行记录、证据日志和周复盘；
- 到期后更新路线信心，不用新叙事覆盖旧证据。

奥德赛工作流完成的标志，不是写出漂亮的三条人生故事，而是至少有一个关键未知进入了现实检验。

# Obsidian 使用指南

## 是否必须使用 Obsidian

不是。Myself 的核心是 Markdown 文件、数据契约和运行协议。Obsidian 提供 Wiki-link、反向链接、模板和本地搜索，是推荐界面，但不是数据库依赖。

## 推荐设置

1. 用生成目录作为独立 vault。
2. 启用官方 Templates 插件，将模板目录设为 `90 模板`。
3. 启用 File recovery，并另外使用 Git、系统备份或压缩快照。
4. 将包含个人资料的 vault 保持为私有，不要误推送到公开仓库。
5. 若使用 Obsidian Sync，仍需在重要写入前创建可验证的 Checkpoint。

## 页面生成

- 日记：复制 `90 模板/日记.md` 到 `04 复盘/日记/YYYY-MM-DD.md`。
- 周复盘：复制到 `04 复盘/周复盘/YYYY-Www.md`。
- 月复盘：复制到 `04 复盘/月复盘/YYYY-MM.md`。
- 季度复盘：复制到 `04 复盘/季度复盘/YYYY-Qn.md`。
- 年度复盘：复制到 `04 复盘/年度复盘/YYYY.md`。

模板中的 `{{date:...}}` 是 Obsidian Templates 风格占位符。如果使用其他工具，请让 Agent 或脚本按实际日期替换。

## 推荐链接方式

- 详情只保留一个 canonical 页面，其他页面使用 Wiki-link 引用。
- 首页只做导航和少量派生状态，不复制财务或计划明细。
- 对话内容先进入收件箱；审阅后才迁移到正式页面。
- 同一事实冲突时保留双方来源，不静默覆盖。

## 隐私提醒

Obsidian 本地存储不等于自动安全。不要保存助记词、私钥、密码、API Key、完整证件号码、未公开漏洞、公司机密或不必要的第三方身份资料。

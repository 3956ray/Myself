# 适用对象与预期成果

## 主要用户

Myself 主要面向约 18–25 岁、正处于教育与早期生涯关键节点的人，包括：

- 高中毕业，正在选择大学、专业、训练路径或间隔年；
- 大学期间开始思考专业、实习、研究、就业或继续升学；
- 大学或研究所毕业，准备进入职场；
- 初入职场后发现原方向不适合，准备重新探索。

年龄不是使用资格或硬性限制。这个范围用于决定默认问题、示例和使用路径：用户可能经验有限、选择很多，也常同时受到家庭期待、升学制度、经济条件和同龄人比较的影响。

## 用户需要完成的进展

项目不承诺帮助用户找到唯一正确或终身不变的目标。一次完整使用后，用户应该能够：

1. 看清当前阶段的资源、约束、责任和重要时间窗口；
2. 区分自己的兴趣与能量信号、外部期待和未经验证的想象；
3. 形成三个不同、包含完整生活而不只是专业或职位的五年版本；
4. 通过真实人物、课程、项目、实习、跟岗或其他低成本原型减少关键未知；
5. 由本人选择未来三年当前愿意投入的方向，同时保留改变方向的条件；
6. 把方向转成未来 90 天能够开始的行动与复查日期。

## 什么叫“相对清楚的方向”

清楚不等于确定未来。一个当前可用的方向至少包含：

- **方向陈述**：未来三年主要探索或建设什么；
- **选择理由**：它连接了哪些本人在意的价值和现实证据；
- **阶段目标**：未来 6–12 个月希望看到什么可观察进展；
- **第一步**：未来 90 天要完成什么行动或原型；
- **边界**：什么不做，不能牺牲什么；
- **改变条件**：出现哪些新证据时复查、调整或换方向。

这份方向可以是专业、职业、能力组合、问题领域或生活方式，不必过早缩成一个职位名称。

## 引导原则

- Agent 通过提问、整理和原型设计帮助用户思考，不替用户给出“你应该做什么”的答案。
- 对经验有限的用户，缺少证据是正常状态；先创造接触现实的机会，不因暂时答不出价值观而贴标签。
- 家庭、老师、同龄人和社会期待都是需要理解的真实影响，但不自动等于用户本人的目标。
- 升学、选专业和第一份工作是重要决定，却不是不可逆身份宣判；保留可迁移能力和替代路径。
- 目标改变不代表以前失败。复查的重点是新证据是否足以支持调整。

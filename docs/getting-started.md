# 快速开始

本项目默认面向约 18–25 岁、正经历高中升大学、选择专业、毕业、升学、初次就业或早期转向的用户。年龄不是限制，详细定位与完成标准见[适用对象与预期成果](audience-and-outcomes.md)。

## 1. 初始化私人 vault

```bash
python3 scripts/init_vault.py /绝对路径/My-Personal-OS
```

初始化器会：

- 复制通用模板；
- 生成当前年份和季度页面；
- 把只读校验器放入 vault；
- 运行第一次结构检查。

目标目录必须不存在或为空，初始化器不会覆盖已有文件。

## 2. 选择使用界面

### Obsidian

选择 “Open folder as vault”，打开新目录即可。不依赖社区插件。建议先启用：

- Files；
- Backlinks；
- Templates；
- File recovery。

File recovery 不能替代正式 Checkpoint。更多说明见 [Obsidian 指南](obsidian.md)。

### 纯 Markdown

直接使用编辑器与 Git 也可以。Wiki-link 是导航增强，不影响大多数 Agent 读取正文。

## 3. 运行首次访谈

把下面提示词交给 Agent：

```text
阅读 AGENTS.md 和 99 系统/首次设置.md，带我完成第一阶段“当前现实”。
一次最多问三个问题；区分事实、感受、解释和假设。
先生成收件箱候选，不要直接修改正式状态。
```

首次设置分七个 Checkpoint：

1. 当前现实与人生维度：资源、约束、风险和需要关注的维度。
2. 工作观、人生观与能量证据：分别澄清意义，并记录至少 7 个有代表性的日子。
3. 人生罗盘与问题重构：形成冲突规则，把卡点改写成可行动问题。
4. 奥德赛计划：构想三种不同的五年生活。
5. 原型与本人选择：通过对话和体验减少未知，由本人选择、组合或新建路线。
6. 三年战略与当前季度：将当前方向转成可执行、可复查的假设。
7. 第一次周复盘：让系统真正进入反馈循环。

如果只想改善当前生活，可以在第 3 步后直接设计小型实验，不必强迫自己进行职业转换。详细说明见 [奥德赛衔接](odyssey-plan.md)。

完成第 6 步时，用户至少应能说明：未来三年的方向、未来 6–12 个月的阶段目标、未来 90 天的第一步，以及哪些新证据会让自己改变方向。

## 4. 批准第一次写入

Agent 应展示：

- 建议修改的文件；
- 当前内容与建议内容的差异；
- 证据和仍不确定的部分；
- 验收、回滚和复查条件。

只批准你已经阅读的明确范围。批准前不应创建正式人生结论。

## 5. 形成最小习惯

系统再完整，也不能替代运行。最低配置只有两件事：

- 每周完成一次 20 分钟复盘；
- 每次重要决定留下一条可复查记录。

在首次方向探索期间，再增加一个临时习惯：每天用 2–5 分钟记录代表性活动的投入与能量，至少持续 7 天。

月、季、年复盘可以在有足够周记录后逐渐加入。

## 6. 更新框架

私人 vault 和框架仓库是两套目录。不要直接 `git pull` 覆盖私人 vault。未来版本应通过迁移说明或 Agent 生成变更提案，再由本人批准合并。

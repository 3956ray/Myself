# 阶段重规划

工作、家庭、健康或资源变化，使原计划的关键前提失效时使用。普通进度波动先通过周复盘处理。

## 操作顺序

1. 将变化、发生时间和来源记入收件箱或证据记录；区分事实、感受、解释和未知。
2. 读取当前状态、[[03 季度/当前季度]]指向的计划，以及本次受影响的实验；保留旧计划，列出仍有效与已失效的前提。
3. 使用[[90 模板/阶段重规划]]建立有界计划。最多三个结果，所有方向共用一个资源上限，列明继续、暂停、替代和冲突优先级。
4. 为关键未知设计最小实验。计划批准与执行开始分开，未发生的行动不写成成果。
5. 按[[90 模板/变更提案]]列出具体差异，通过验证、本人批准和 Checkpoint 后，再更新正式页面及日志。
6. 在周复盘查看实际投入与结果，到 `review_due` 决定继续、缩小或停止。没有反馈时记录接触和观察是否充分。

## 跨季度规则

- 阶段计划的起止日期可以跨季度，不因此延长季度的日历边界。
- [[03 季度/当前季度]]保留当前季度入口，并链接额外生效的阶段计划。
- 季度切换仍需独立复盘与批准；未完成的实验可继续引用同一个实验页面，避免重建后丢失历史。
- 不将旧计划整体静默覆盖；仅明确哪些目标从哪个日期起被替代。

## 最小输出

一份变化摘要、一份有界计划、最多三个下一步，以及一处明确的复查日期。缺少关键事实时保留候选与缺口，先完成不依赖该事实的整理。

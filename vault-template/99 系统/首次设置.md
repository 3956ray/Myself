# 首次设置

首次设置的目标不是一次性回答“我是谁”，而是帮助处在升学、毕业或初入职场等转折期的用户，形成可以用现实反馈更新的方向 v1。预期成果见[[99 系统/适用对象与成果]]。Agent 每次最多问三个问题，先保存候选，再由本人批准正式状态。完整流程通常需要数周观察与原型，不必在一次对话中完成。

## 先选择入口

四种入口共享同一套页面，只是起点和深度不同：

| 当前情境 | 推荐起点 | 不要急着做 |
|---|---|---|
| 高中升大学／选择专业或训练路径 | 从 Checkpoint 1 完整进行 | 把一次选择当成终身身份 |
| 大学期间探索实习、研究、就业或升学 | 先盘点已有接触，再做能量观察与奥德赛 | 只比较名称、排名或想象 |
| 大学／研究所毕业进入职场 | 先做现实期限与资源盘点，再进入奥德赛 | 直接要求 Agent 推荐职位 |
| 初入职场后准备换方向 | 从能量、问题重构与现实原型开始 | 未验证就辞职或高成本转向 |

## Checkpoint 1：当前现实与人生维度

目标页面：[[01 基础/当前状态]]、[[01 基础/人生维度]]

- 当前教育／工作阶段、责任与真实时间安排；
- 关键选择窗口：申请、考试、毕业、实习、求职或资格期限；
- 财务安全摘要、健康、关系、支持系统与地点约束；
- 各人生维度的当前证据、瓶颈和暂时不追求的事项。

验收条件：当前事实和未来愿望已经分开；敏感信息只保留规划所需摘要；分数有事实依据或标记为 `?`。

## Checkpoint 2：工作观、人生观与能量证据

目标页面：[[01 基础/工作观与人生观]]、[[05 日志/投入与能量日志]]

1. 分别写学习／工作为何值得投入、什么使人生值得过；没有正式工作经历也可以从课程、社团、项目、照护和兼职经验回答。
2. 检查二者相互支持、冲突和只停留在口号的部分。
3. 使用[[90 模板/投入与能量记录]]记录至少 7 个有代表性的日子；生活变化较大时延长至两至四周。
4. 区分活动内容、环境、人际、节奏与睡眠等混杂因素。

验收条件：结论来自多日观察和本人陈述，而不是 Agent 猜测或一次高峰／低谷。

## Checkpoint 3：人生罗盘与问题重构

目标页面：[[01 基础/人生罗盘]]、[[02 战略/当前要解决的问题]]

- 从前两步提炼投入信号、反目标、阶段性“足够”、底线和冲突规则；
- 描述三至五年后／下一个重要阶段的普通工作日；
- 选一个反复卡住的问题，区分事实、感受、解释、无法改变的现实和可影响部分；
- 写出至少三个“我可以怎样……”的问题框架。

验收条件：罗盘能在价值冲突时帮助选择；当前问题开放、可行动且没有偷塞唯一答案。

## Checkpoint 4：三个奥德赛计划

目标页面：[[02 战略/奥德赛计划]]

按照官方方法构想未来五年的三种生活：

1. 延续当前轨迹；
2. 当前计划不再可行时的替代路线；
3. 暂时放下金钱与社会期待的路线。

每条都包含工作、关系、健康、玩乐／体验、关键时刻和普通日常，并有自己的标题。三条路线先独立完成，不在生成阶段自动折中或排名。

验收条件：三个计划足够不同且都值得认真考虑；已识别跨计划共同元素和每条路线的关键未知。

## Checkpoint 5：原型与本人选择

使用[[90 模板/奥德赛原型访谈]]与[[90 模板/奥德赛原型实验]]：

- 先进行便宜、快速、容易开始的原型对话或体验；
- 优先验证会改变选择的未知，而不是收集赞同；
- 比较真实日常、投入与能量、门槛、代价和其他人生维度；
- 记录支持与反对证据、样本限制和仍未回答的问题。

建议至少完成两次原型对话和一次原型体验；无法完成时记录原因。然后由本人选择一条路线、组合不同路线的元素或创建新版本。Agent 不能依据评分替用户选择。

## Checkpoint 6：三年战略与当前季度

目标页面：[[02 战略/三年情景|三年战略]]、[[02 战略/__INIT_YEAR__ 年度主题]]、[[03 季度/当前季度]]指向的计划。

- 把当前选择转成三年后可观察的状态、阶段路径和关键假设；
- 保留 Plan B、基本安全用的 Plan Z 和切换信号；
- 选择当前季度最多三个可观察结果；
- 为每项结果定义证据、失败和停止条件，并写出不做清单。

验收条件：计划能在现有时间、资源和责任中执行，并持续为方向提供证据。

完成后，用户应能用自己的话说清：未来三年的方向、未来 6–12 个月的阶段目标、未来 90 天的第一步，以及什么新证据会让自己调整方向。

## Checkpoint 7：第一次反馈循环

使用[[90 模板/周复盘]]完成真实周复盘：时间与精力实际分配、支持与反对证据、一个被忽略的风险、下周最多三个重点，以及是否需要正式页面变更。

完成真实复盘才代表系统开始运行，而不是只填完文档。

## 每个 Checkpoint 的写入流程

候选访谈 → 分类与脱敏 → 页面差异提案 → 校验／Verifier → 本人批准 → Checkpoint → 单写者更新 → 复查。

奥德赛方法、官方材料与项目扩展的边界见[[99 系统/奥德赛方法与来源]]。

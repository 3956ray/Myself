# 首次设置

首次设置的目标不是一次性回答“我是谁”，而是建立足以开始迭代的 v1。Agent 每次最多问三个问题，先保存候选，再由本人批准正式状态。

## Checkpoint 1：当前现实

目标页面：[[01 基础/当前状态]]

需要了解：

- 当前身份、责任、住所、工作／学习和真实时间安排；
- 收入稳定性、基础支出、安全垫、债务、保险和现实期限；
- 健康、精力、重要关系、支持系统和地点约束；
- 已有能力、资源、风险和信息缺口。

验收条件：当前事实和未来愿望已经分开；敏感信息只保留规划所需摘要。

## Checkpoint 2：认识自己与人生罗盘

目标页面：[[01 基础/人生罗盘]]

访谈顺序：

1. 三段高投入经历：当时做什么、为什么愿意继续、环境有什么共同点？
2. 三段高消耗经历：内容、节奏、关系和环境分别造成什么影响？
3. 三种明确不想要的人生状态。
4. 健康、关系、自由、成长、财富等发生冲突时的强制排序。
5. 对收入、资产、时间、成就和关系的阶段性“足够”定义。
6. 30 岁时一个普通工作日，而不是节日或幻想高峰。

验收条件：罗盘包含冲突规则、底线和仍待验证的假设，不把社会标准当作个人答案。

## Checkpoint 3：三条奥德赛与现实原型

目标页面：[[02 战略/三年情景]]

- 路线一：沿目前方向继续、但主动设计得更好的生活；
- 路线二：如果路线一不再可行，会怎样生活；
- 路线三：基本生活得到保障、暂时放下身份与评价约束时会探索什么；
- 每条路线包含六词标题、3–5年里程碑、普通一周、资源与代价、2–3个问题和仪表盘；
- 找出共同底盘，并为仍有吸引力的路线设计最小现实原型；
- 可以选一条当前工作路径，但记录信心、替代路线和改变选择的证据。

Agent 引导方法见 Myself 仓库的 `docs/odyssey-planning.md`。验收条件：三条路线在生活结构或身份上确实不同；至少一个关键未知进入现实检验；不宣称预测准确。

### 智囊团的顺序

首次访谈可以记录想参考的人、作品和原因，作为候选名单。完整智囊团放在三条奥德赛草案之后：用来指出盲点、代价、隐藏假设和可行原型，不替本人生成价值观或投票决定路线。

## Checkpoint 4：当前季度

目标页面：[[03 季度/当前季度]]指向的计划。

- 结合现实约束，选择最多三个可观察结果；
- 为每项结果定义证据、失败和停止条件；
- 写出本季度明确不做清单；
- 不把所有人生维度都塞进一个季度。

验收条件：计划可以在现有时间和资源中执行，并且能为奥德赛路线提供证据。

## Checkpoint 5：第一次反馈循环

使用[[90 模板/周复盘]]完成真实周复盘，并检查：

- 时间和精力实际分配；
- 支持与反对当前方向的证据；
- 一个被忽略的风险；
- 下周最多三个重点；
- 是否需要正式页面变更。

完成这一项才代表系统开始运行，而不是只完成了文档结构。

## 首次设置写入流程

每个 Checkpoint 都遵循：

候选访谈 → 分类与脱敏 → 页面差异提案 → 校验／Verifier → 本人批准 → Checkpoint → 单写者更新 → 复查。

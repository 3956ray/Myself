# 数据契约

## 通用属性

| 字段 | 作用 |
|---|---|
| `type` | 实体类别 |
| `id` | 创建后不变的唯一标识 |
| `status` | 生命周期状态 |
| `version` | 页面契约或内容版本 |
| `updated` | 最后修改日期 |
| `as_of` | 内容有效到哪一天 |
| `time_scope` | `current`、`ongoing`、有界期间、未来目标或 `mixed` |
| `scope_start` / `scope_end` | 有界期间的起止日期 |
| `source_refs` | 原始输入 |
| `evidence_refs` | 支持结论的证据链接或 ID |
| `confidence` | `low`、`medium`、`high`，不是概率真相 |
| `sensitivity` | `public`、`private`、`restricted` |
| `review_due` | 应复查日期 |

机器状态统一使用：

- `verifier_status`：`pending`、`validated`、`rejected`、`insufficient_evidence`、`not_required`。
- `human_approval`：`pending`、`approved`、`approved_with_changes`、`rejected`、`not_required`。

## 生命周期

- 正式知识：`draft → active → superseded → archived`
- 候选变更：`proposed → validated → completed` 或 `proposed → rejected`
- 证据：`captured → validated / rejected → archived`
- 实验：`proposed → active → completed / failed / cancelled → archived`
- 决策：`open → completed → superseded / archived`

状态不能只因为 Agent 声称完成而改变，必须满足验收条件。

## 核心实体

| 实体 | 载体 | 语义 |
|---|---|---|
| State | `01 基础/` | 当前事实与稳定约束 |
| Compass | 人生罗盘 | 价值、反目标、足够与底线 |
| Strategy | `02 战略/` | 中长期假设和可能情景 |
| Plan | `03 季度/` | 有界期间的结果与资源分配 |
| Evidence | `05 日志/` 或独立记录 | 支持或反对判断的输入 |
| Decision | 决策记录 | 本人批准的选择 |
| Experiment | `06 实验/` | 可证伪假设与现实反馈 |
| Review | `04 复盘/` | 对期间证据的归纳 |
| Change Proposal | 变更提案 | 正式写入前的差异与范围 |
| Run | 工作流运行记录 | 输入、验证、批准、Checkpoint 与结果 |

## Canonical 与派生

- 基础、战略和季度中的正式页面是对应领域的 canonical 页面。
- 首页是派生导航，不复制大量会变化的明细。
- 对话摘要先进入收件箱或变更提案。
- 同一事实冲突时保留冲突、来源和待确认项，不静默选择。

## 隐私等级

- `public`：可以公开或交给外部模型。
- `private`：个人资料，只按任务需要使用。
- `restricted`：财务、医疗、身份、公司或他人资料，默认不进入 Worker，上下文必须脱敏。

# Personal OS 运行规则

## 系统边界

本 vault 是唯一正式状态源。聊天、网页、其他应用和 Agent 输出是候选输入，不能直接覆盖正式状态。

## 核心循环

观察事实 → 形成解释 → 做出选择 → 执行实验 → 收集证据 → 复盘更新。

## 五类内容分开

1. **Fact**：可以观察和复查的事实，需要时间与来源。
2. **Feeling**：本人的主观体验，需要发生时间。
3. **Interpretation**：对事实的解释，需要关联事实和替代解释。
4. **Hypothesis**：尚待验证的判断，需要成功、失败或停止条件。
5. **Decision**：本人基于现有证据作出的选择，需要依据、信心和复查日期。

不要因为一天状态差就修改三年战略，也不要因为长期愿景宏大而忽略本周事实。

## 修改节奏

- [[00 首页]]：每周更新派生状态。
- [[01 基础/当前状态]]：每月或现实明显改变时更新。
- [[01 基础/人生罗盘]]：每半年复查。
- [[02 战略/三年情景]]：每季度复查。
- 季度计划：季度开始和结束时更新。
- 证据、决定、变更和复盘：追加历史，不静默改写。

## 写入协议

1. **Capture**：记录原始输入、来源和发生时间。
2. **Normalize**：分类、去重、标注时间与隐私。
3. **Evidence**：连接支持和反对证据。
4. **Proposal**：列出目标页面、实际差异和验收条件。
5. **Verify**：先确定性检查，需要判断时再独立验证。
6. **Human Gate**：本人批准、修正或拒绝明确范围。
7. **Checkpoint**：写入前建立可恢复快照。
8. **Commit**：一个 Writer 串行修改批准内容。
9. **Trace/Eval**：再次校验，记录差异并在现实中复查。

## 最小可行习惯

如果时间不足，只做两件事：

1. 每周一次 20 分钟复盘。
2. 每次重要决定留下一条记录。

## 隐私与安全

永远不要写入密钥、助记词、账号凭据、完整证件号码、公司机密、未公开漏洞或不必要的第三方身份资料。`restricted` 内容只在完成当前任务所需的最小范围内进入 AI 上下文。
